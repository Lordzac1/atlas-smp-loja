# Loja do ATLAS SMP (GitHub Pages)

Ficheiro gerado para publicação direta no GitHub Pages.

## Como publicar:
1. Extraia o ficheiro `index.html` de dentro deste ficheiro `.zip`.
2. Vá ao seu repositório no GitHub (`lordzac1/atlas-smp-loja`).
3. Faça upload ou cole o conteúdo dentro do ficheiro `index.html`.
4. Guarde (Commit) e aceda a `https://lordzac1.github.io/atlas-smp-loja/`.
